# かぞくで あそぶ（Family チーム, v1.1）

SPEC §11.2 の 2（親子・兄弟で対戦、ローカル）と 4（キャラカードの印刷）。
根拠: `reports/らくがきバトル 競合と差別化.md`（保護者の懸念の上位は見知らぬ人との交流、子どもの 52% は保護者と一緒に遊びたい、実物のカード人気）。
どちらも**端末内だけで完結**する（Firebase・サーバー・広告・ネットワークを使わない）。

## 1. かぞくで たいせん（`app/lib/features/family_battle/`）

| ファイル | 内容 |
|---|---|
| `family_setup.dart` | `FamilyPlayer` / `FamilyBattleConfig`、ハンデの計算 `battleLevel()`、`familyFighterSetup()`、プリセットの名前 |
| `family_battle_session.dart` | 1 台で交互に選ぶ対戦（a が選ぶ → b が選ぶ → `resolveTurn`） |
| `family_setup_screen.dart` | `/family`: 2 人のキャラ・名前・ハンデを選ぶ |
| `family_battle_screen.dart` | `/family/battle`（`extra`: `FamilyBattleConfig`）: かくし画面 → わざ選び → 演出 → 結果 |

### 流れ
1. ホームの「かぞくで たいせん」（ピンクのボタン。オンラインの許可とは無関係に常に出す）
2. 準備: あか（side a）とあお（side b）がそれぞれ ずかんからキャラを選ぶ。初期値はあか = いちばん新しいキャラ、あお = その 1 つ前（1 体しかいなければ同じキャラ）。**同じキャラ同士（ミラー）も選べる**。そのときバトルの文言は「ねこまる（あか）」「ねこまる（あお）」と色を付けて区別する
3. ターンごとに: **かくし画面**（チーム色の全面、「あか チームの ばん！ / あお チームは みないでね / あか チームが タップ」）→ あかが選ぶ → かくし画面（あおの番）→ あおが選ぶ → 2 人で演出を見る → 次のターンのかくし画面。かくし画面ではわざのボタンを出さない。メッセージ欄にも選んだわざは出さない
4. 結果: 「〇〇の かち！」「ふたりとも よく がんばったね！」→「もういちど」（同じ設定・新しい seed）/「メンバーを かえる」（準備画面へ戻る。選択は残る）/「おわる」（ホーム）

### 決定事項
- **名前はプリセットだけ**（あか チーム・あお チーム・おとうさん・おかあさん・おにいちゃん・おねえちゃん・おとうと・いもうと・おじいちゃん・おばあちゃん・ぼく・わたし）。自由入力をさせないので NG チェックは不要。色は位置で固定（あか = 下 = side a、あお = 上 = side b）
- **ハンデ**（エンジンはそのまま。変えるのは `FighterSetup` のレベルだけ）
  - 「おなじ レベルで たたかう」: **初期値 ON**。低い方のレベルを高い方に合わせる（強くなる方向だけ。下げると育てたキャラが弱く感じるため）
  - 各プレイヤーの「ハンデ」: なし / Lv＋3 / Lv＋5 / Lv＋10。おなじ レベルの後に足す。最大 Lv（30）で頭打ち
  - ステータスは `statsAtLevel(spec, baseStats, 戦うレベル, そのキャラの振ったたね, isShobo)`。つまり「そのキャラがそのレベルになったとき」と同じで、エンジンから見て普通のセットアップ。ひっさつの威力（Lv20 でんせつ +20）もレベルに従う。保存はしない
  - 準備画面には「戦うレベル」だけを出す（上がったときは ↑）。じょうずさ・のびのび度・成長率は一切出さない
- **経験値なし**（「れんしゅう バトル。けいけんちは ふえないよ」と準備画面に書く）。理由: 1 人でミラー戦を繰り返す・大人が代わりに戦う、で簡単に稼げてしまう。上限付きの少量も検討したが、CPU 戦と広告ブーストの設計（SPEC §4.2/§7）を崩さないため入れない
- 時間制限なし（オンラインの 20 秒タイマーは使わない）。中断は戻るボタンでいつでも
- 乱数: `deriveSeed(seed, 0)` だけ（AI がいないので AI ストリームは使わない）。seed は `randomProvider`
- 絵は `CharacterPicture`（描き足したパーツ込みの合成画像）。**両プレイヤーが描いた わざの え**を `BattleArena(effectImages: {a: watchMoveEffects(a), b: watchMoveEffects(b)})` で飛ばす（docs/LOOP.md §5）。ミラー戦では同じ絵が両方から飛ぶ
- 両プレイヤーとも 1 台の画面を共有するので、HP・ゲージは常に見せる（隠すのはわざの選択だけ）

## 2. キャラカード印刷（`app/lib/features/card_print/`）

| ファイル | 内容 |
|---|---|
| `card_content.dart` | `CardContent`（カードに載せるもの）、`cardContentFor()`、星の計算 `cardStars()` |
| `card_pdf.dart` | `buildCardPdf(cards, fonts:, layout:)`（純 Dart、`pdf` パッケージ） |
| `card_preview.dart` | 画面用のプレビュー（同じ `CardContent`・同じ配置を Flutter で描く） |
| `card_output.dart` | `CardOutput`（印刷 / 共有。本番は `printing`）、`cardFontsProvider` |
| `card_select_screen.dart` | `/zukan/cards`: ずかんから最大 9 体を選ぶ |
| `card_print_screen.dart` | `/zukan/cards/print?ids=a,b`: プレビュー、レイアウト切替、印刷・共有 |

入口: ずかんの右上「カード」（複数選択）、キャラ詳細の「カードに する」（1 体）。

### カード（63 × 88 mm、トレーディングカードの大きさ）
- 上から: 名前（長い名前は縮小）と Lv / **絵を大きく**（`characterDisplayImageProvider` = `DisplayImageService.displayImageFor`。紙の絵の切り抜きに、描き足したパーツを合成したもの。パーツが無ければ切り抜きそのもの） / ぞくせい（アイコン + ひらがな）/ ステータスの星 / わざ 4 つ / 「らくがきバトル」ロゴ文字と「うまれた ひ 2026.10.1」
- 進化の枠: ふつう = ぞくせい色の細い枠、かがやき = 太い枠 + きらきら + 「かがやき」ラベル、でんせつ = 金の太い枠 +「でんせつ」
- フレームパック（`frame_pack_1`）を持っていて `cardFrame` を選んでいれば、カードの地の色が ほし / はな / にじ になる
- **星は「そのキャラ自身のいちばん高いステータス = ★5」に対する割合**（四捨五入、最低 ★1）。キャラの「とくいな ところ」の形だけを見せ、強さ・絵のじょうずさは読み取れない（同じ配分なら Lv1 でも Lv30 でも、しょぼでも普通でも同じ星）。数値（ステータス・skill・energy）は一切載せない。強さの目安は Lv だけ
- 日付は印刷日ではなく**キャラが生まれた日**（＝絵を描いた日。子どもの絵に日付を残す意味がある）
- アイコンはフォントを使わず SVG パスで描く（Material Icons のフォントは release でツリーシェイクされるため）
- フォント: 同梱の Zen Maru Gothic（Regular/Bold）を `rootBundle` から読み、PDF には使った文字だけのサブセットを埋め込む（PDF は数十〜数百 KB で、大きさはほぼ原画の画像で決まる）

### PDF のレイアウト
- 「A4に ならべる」（初期値）: A4 縦に 3 × 3（189 × 264 mm、中央寄せ）、灰色の切り取り線、上に「せんに そって きってね」、下に保護者向け「印刷するときは『実際のサイズ（100%）』を選ぶと…」。10 枚以上なら次のページ（選択画面は 9 枚まで）
- 「1まいずつ」: 63 × 88 mm のページを 1 枚ずつ（共有・カード用紙・写真プリント向け）

### 印刷・共有とゲート
- プレビューは子どもも自由に見られる。「いんさつ する」「PDFで おくる・ほぞん」は**押すたびに保護者ゲート**（`parentalGateProvider`）→ 通ったときだけ PDF を作り、`Printing.layoutPdf`（Android の印刷ダイアログ）/ `Printing.sharePdf`（共有シート）へ渡す。ゲートを通らなければ PDF も作らない
- 失敗時は「うまく できなかったよ。もういちど ためしてね」
- ファイル名は `oekaki_fighters_cards_YYYYMMDD.pdf`（子どもの名前やキャラ名を入れない）

### パッケージ
- `pdf: ^3.13.1`（2026-09-19、Dart >=3.12）、`printing: ^5.15.1`（同日、Flutter >=3.41）。どちらも DavBfr/dart_pdf、Apache-2.0
- `printing` の Android 側: minSdk 21 / compileSdk 34 でビルドされ、アプリの compileSdk 36 と共存する。追加されるのは FileProvider（`${applicationId}.flutter.printing`、exported=false）だけで、**権限は増えない**（`scripts/check_release.sh` の許可リストに影響なし）。ネットワーク不要
- PDF の保存（`doc.save()`）は `pdf` が別 isolate で行う（テストでは同じ isolate）

## 3. テスト
- `test/features/family_battle/family_battle_test.dart`: ハンデ（おなじ レベル、ブースト、上限、`statsAtLevel` と一致）、ミラー名、セッションがエンジンと一致、**ウィジェットで 1 戦通し**（かくし画面の文言と交互、かくし中はわざが見えない、Lv と HP にハンデが反映、経験値・レベルが変わらない、もういちど、戻る）、1 体だけのミラー戦とプリセット名、キャラなし
- `test/features/card_print/card_pdf_test.dart`: 星、内容、PDF（`%PDF-`、ページ数、MediaBox、**ToUnicode CMap で文字を復元して名前・ロゴを確認**、skill の文言や生の数値が無いこと）、A4 で 10 枚 → 2 ページ
- `test/features/card_print/card_print_screen_test.dart`: 詳細 → カード → ゲート拒否で何も出ない / 通れば印刷、ずかんの複数選択（9 枚まで）→ A4 / 1 まいずつ の共有、失敗メッセージ
- `test/features/family_battle/loop_integration_test.dart`: カードがパーツ込みの合成画像を使う、家族対戦で描いた わざの え が飛ぶ（もう一方は既定のエフェクト）
- `pdf_text.dart`: 非圧縮 PDF から文字を取り出すテスト用の小さな関数
