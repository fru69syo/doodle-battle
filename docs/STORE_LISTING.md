# ストア掲載情報と Play Console の申告（Release/QA チーム）

Google Play Console で入力する内容の**推奨回答**をまとめたものです。**v2.0（2026-10-14 時点の実装）**に合わせています。根拠は `docs/SPEC.md`（v2.0。§2・§7・§9・§10・§11）、`docs/BACKEND.md`（§3・§4・§5・§16・§17）、`docs/COMPLIANCE.md`。
仕様が変わったとき（課金を有効にしたとき、広告 SDK や Firebase の SDK を増やしたとき、サーバーに送るデータを増やしたときなど）は、このファイルと Play Console の両方を更新してください。

- 掲載文とグラフィックの実体: `store/metadata/ja-JP/`（fastlane supply の形式。`fastlane android metadata` でアップロードできます）
- 文字数・画像サイズ・禁止語のチェック: `python3 scripts/check_listing.py`（CI でも実行）
- 「PM 判断」と書いた項目は、決めてから入力してください

v2.0 の説明文で伝えること（順番もこのとおり）: 紙でもアプリでも描いた絵が 2.5D で動くキャラになる → わざを選ぶだけのリアルタイムバトル（さきどり・おまかせ）→ 100 ステージ → チャットなし・バッジつきの安全なオンライン対戦 → かぞくで たいせん → AR・カード・動画 → 保護者向け（無料・課金なし・ガチャなし・保護者ゲート・広告の条件）→ データ（**絵は AI の学習に使わない**、Claude だけを使う）。

書き方のルール（Play のメタデータポリシーと SPEC）:
- **書かないこと**（`check_listing.py` が禁止語で検査）: 隠し要素（内部名・「AI の絵は弱くなる」など）、子どもの絵らしさなどの内部の値、絵の上手さ・点数など**子どもの絵を評価していると受け取れる表現**、v1 の内容（ターン制、全 30 ステージ、課金の商品、「AI 画像は取り込めません」）。
- 「No.1」「最高」などの順位や比較の表現、ユーザーの声の引用、キーワードの羅列、絵文字、関係の無いアプリ名は使いません。
- 説明文に書いた安全の仕組み（チャットなし、保護者ゲート、課金なし・ガチャなし、広告の前のお知らせ、オンラインの絵は審査のあとで表示、バッジは下がらない・数字を出さない、データ削除）は、**リリースするビルドで実際にそうなっていること**を QA で確かめます（`docs/QA_CHECKLIST.md` §13.3）。実装が変わったら説明文も直してください。
- 「Teacher Approved」「ファミリー向けに認定」などのバッジを、自分で名乗ってはいけません。
- 同じジャンルのほかのアプリの名前は、タイトル・説明・スクリーンショットのどこにも書きません。

- 仮のグラフィックは `store/tools/gen_graphics.py` でプログラム生成しています。文字は **Zen Maru Gothic Black**（SIL OFL 1.1、`store/fonts/OFL-ZenMaruGothic.txt`。フォントはリポジトリに入れず、固定コミットから SHA-256 を確かめてダウンロード）。本番のグラフィックに差し替える場合は、同じファイル名で上書きし、`python3 scripts/check_listing.py` と `cd app && dart run flutter_launcher_icons` を実行してください。アダプティブアイコンの前景は 1024×1024 で、キャラクターを中央 61%（直径）の円の中に収めます。

- **v2.0 の順番**: ① かいた えが うごく キャラに（紙の写真 → 誕生画面）② わざを えらぶだけ！リアルタイム バトル（2.5D のステージ）③ アプリの なかでも おえかき（お絵かきツール）④ うごく ところを じぶんで なおせる（関節の手直し）⑤ ぜんぶで 100 ステージ（ステージ選択、星つき）⑥ バッジが そだつ オンライン たいせん（ロビーとくまのバッジ）⑦ かぞくで たいせん ⑧ おうちの かたへ（チャット・ガチャなし／無料・アプリ内課金なし／設定と外部リンクは保護者の確認の先／広告・オンラインは初期設定でオフ／絵は AI の学習に使いません）。予備: どうが、カード、おだい、そだてる、撮影のコツ、ずかん。
- スクリーンショットのルール:
  - **隠し要素のキャラ（AI やプロの絵）を写さない**。絵を評価していると受け取れる画面（点数・上手さ）も写さない。`screenshots_test.dart` は、写すキャラがすべて子どもの絵（隠し要素でない）であることをテストで確かめます。
  - 実際のゲーム画面を使います。子どもの**顔や名前、写真**が写らないようにします。本物の子どもの絵を使うときは、保護者から**書面で許可**をもらいます（今は合成した絵だけ）。
  - 広告の画面を大きく見せない。課金の画面は無い（v2.0）。

### Teacher Approved について
- ファミリーポリシーに準拠し、公開されているアプリは自動的に審査の対象になります（申請はできません）。
- **注意**: 「子どもがほかのユーザーと交流できるソーシャル機能」があるアプリは対象外とされています。オンライン対戦（ほかの子の絵が表示される）がこれに当たると判断される可能性があります。オンラインは初期設定でオフ・保護者ゲートの先・チャットなしです。狙うかどうかは **PM 判断**。
- v2.0 は課金なしで、広告も保護者の許可制なので、「しつこい広告・購入への誘導」の観点では有利です。

### 6.2 データの種類（2026-10-14、v2.0 の実装どおり）

「任意」= 保護者が「おうちのひと」（または初回セットアップ）で機能を許可したときだけ集める（初期値はすべてオフ）。Anthropic と Google（Firebase・Cloud Run）は**サービスプロバイダ**（こちらに代わって処理する）なので、Play の定義では「共有」に当たりません。AdMob は Google の「Play のデータ開示」で「収集して共有する」とされているので、広告由来のものは「共有: はい」にします。

| カテゴリ / 種類 | 収集 | 共有 | 任意か | 目的 | どこで（いつ） |
|---|---|---|---|---|---|
| 個人情報 / ユーザー ID | はい | いいえ | 任意 | アプリの機能、不正防止・セキュリティ | Firebase 匿名認証の uid（クラウド判定かオンラインを許可して最初にサーバーを使ったとき）。表示名（プリセット語の組み合わせ）・レートと紐づく。対戦サーバーへの接続は ID トークンと App Check で確認 |
| 写真と動画 / 写真 | はい | いいえ | 任意 | アプリの機能 | 切り抜いた絵の PNG。クラウド判定（`judgeDrawing`）と Lv10・Lv50 の技づくり（`generateMove`）は保存せず Claude が処理。オンライン登録（`registerCharacter`）は Claude の審査のあと Storage に保存し、対戦相手に表示。**一時的な処理だけではない**（登録で保存する）ので「エフェメラル」にはしない |
| アプリのアクティビティ / その他のユーザー作成コンテンツ | はい | いいえ | 任意 | アプリの機能、不正防止・セキュリティ | オンライン登録時: キャラ名、わざの名前と AI の提案、レベル・経験値、絵の特徴量、関節の設定（`rig`）、絵の作り方（camera / canvas）と、**アプリで描いた絵の線の要約**（線と点の数・色・描いた範囲。**線そのものは端末から出ない**）。通報: `reportCharacter`（選択式の理由）、`reportAiSuggestion`（対象の言葉と選択式の理由） |
| アプリのアクティビティ / アプリの操作 | はい | **はい** | 任意 | アプリの機能、広告、不正防止・セキュリティ | リアルタイム対戦（`rtMatches`: 対戦相手・勝敗・経験値・決着の理由。`replays`: 選んだわざの入力、**30 日で TTL 削除**）、Elo のレート・1 日の対戦数（`users.rated`、数字はアプリに出さずバッジで表示）。広告の表示・タップ（AdMob、共有あり。広告を許可したときだけ） |
| アプリの情報とパフォーマンス / クラッシュログ | はい | いいえ | 任意 | 分析 | Firebase Crashlytics。「ふぐあいの じょうほうを おくる」をオンにしたときだけ（初期値オフ、マニフェストで無効化済み） |
| アプリの情報とパフォーマンス / 診断 | はい | **はい** | 任意 | 分析、広告、不正防止 | Crashlytics（端末の状態など。共有なし）と AdMob（SDK の性能情報。共有あり） |
| デバイスまたはその他の ID | はい | **はい** | 任意 | 分析、広告、不正防止・セキュリティ | Firebase のインストール ID（Crashlytics をオンにしたとき）、App Check（サーバー機能を許可したとき）、AdMob のアプリセット ID（広告を許可したとき）。**広告 ID は収集しない** |
| 位置情報 / おおよその位置情報 | はい | **はい** | 任意 | 広告、不正防止 | AdMob が IP アドレスからおおよその地域を推定する（広告を許可したときだけ）。こちらのサーバーは位置を推定しない |
| 金融情報 / 購入履歴 | **いいえ** | いいえ | | | v2.0 はアプリ内課金なし |

- **申告しなくてよいもの（v2.0 で確認したデータの流れ）**:
  - **お絵かきツールの線**: `StrokeDrawing` は端末の中（`PuppetStore`）だけに保存。サーバーに送るのは登録時の線の**要約**（上の表）だけ。
  - **コストモード**: アプリと対戦サーバーは `config/costMode`（全員共通の設定）を読むだけで、ユーザーのデータは増えない。切り替わっても子どもの画面は変わらない。
  - **ゴースト**: ほかの子が登録したキャラ（スナップショット）を使う。ゴーストの持ち主の uid は相手に送らない。
- **AI の学習には使わない**: お子さまの絵・名前を、当方も Anthropic も AI の学習に使いません（Anthropic の API の入力は同社のモデルの学習に使われない）。データセーフティの目的に「AI の学習」は含めず、説明文（■ データの取り扱い）・同意画面（`NoAiTrainingNotice`）・プライバシーポリシー（`#no-ai-training`）に明記しています。AI は **Claude だけ**（Gemini・Vertex AI は使わない。SPEC §11.1）。
- 収集**しない**もの（`check_release.sh` で権限を検査）: 名前・メール・電話番号・住所、正確な位置情報、連絡先、音声、カレンダー、SMS、ほかのアプリの一覧、ウェブの閲覧履歴、健康情報、**広告 ID**、購入履歴。
- 匿名サインインは保護者がクラウド判定かオンラインを許可するまで行わないので、ユーザー ID は「任意」で申告できます。
- Firebase の各 SDK が集めるデータは、Firebase の「Google Play のデータセーフティ セクションの準備」のページで、**使う SDK ごとに**確認してください（Auth、Firestore、Functions、Storage、App Check、Crashlytics）。Google Analytics for Firebase は**使いません**（`check_release.sh` が Analytics のコンポーネントを見つけたら失敗）。
- AdMob の「データの開示」（`https://developers.google.com/admob/android/privacy/play-data-disclosure`）を申請の前にその時点の内容でもう一度確認してください。

### 6.3 削除について（プライバシーポリシーと削除ページに記載済み）
- アプリ内: おうちのひと → すべてのデータを削除。端末のデータ（線の記録・関節の設定を含む）、サーバーのプロフィール、登録したキャラ（画像を含む）、v1 の対戦と v2 の `rtMatches`・`replays`、通報、認証ユーザーをすべて削除します（`deleteMyData`、BACKEND §5）。クラッシュレポートの送信もオフになり、未送信のレポートを削除します。
- ウェブ: `delete.html` の手順（メール）で依頼すると、運営が本人確認（アプリの「サポート ID」）をしてから代わりに削除します（30 日以内）。
- 保存しないもの: クラウド判定・技づくりの画像（処理が終われば破棄）。Anthropic 側では原則 30 日以内に削除（オーナーが契約を確認: RELEASE.md §1.7）。クラッシュログは Crashlytics で 90 日。対戦の入力の記録は 30 日。

## 7. 権限の説明（社内メモ。レビューで聞かれたとき用）

| 権限 | 理由 |
|---|---|
| CAMERA | 紙の絵を撮る、AR。使う直前に許可を求める |
| INTERNET / ACCESS_NETWORK_STATE | クラウド判定とオンライン対戦（どちらも保護者が許可したとき）、広告、オフラインかどうかの判定 |
| WRITE/READ_EXTERNAL_STORAGE（maxSdkVersion 28） | Android 7〜9 で AR の写真をギャラリーに保存するため。Android 10 以降は不要 |
| WAKE_LOCK / FOREGROUND_SERVICE / RECEIVE_BOOT_COMPLETED | ライブラリ（WorkManager など）由来。アプリ自身は使わない |
| （外したもの）AD_ID、ACCESS_ADSERVICES_AD_ID / ATTRIBUTION / TOPICS | Mobile Ads SDK が足すが、子ども向けアプリなのでマニフェストで削除 |
| （外したもの）com.android.vending.BILLING | Play Billing Library が足すが、v2.0 は課金なしなのでリリースビルドで削除（残っていると「アプリ内購入あり」と表示される場合がある。`app/android/app/src/noIap/AndroidManifest.xml`、`IAP_ENABLED=true` でビルドしたときだけ残る） |

許可リスト以外の権限が入ると `scripts/check_release.sh` が CI とリリースを止めます。足すときは許可リスト・この表・データセーフティを一緒に更新し、PM の承認を得てください。

## 8. アプリ内アイテム（v2.0 では作らない）

SPEC §10.2: **無料で公開し、課金アイテムは出さない**。コードは `IAP_ENABLED`（既定オフ）で残してあり、オーナーの副業申請が通ったら有効にします。それまで Play Console に商品を**作らない**でください（作っても売られませんが、ストアの表示や審査の質問が変わります）。

有効にするときの予定（価格は PM が確定）:

| 商品 ID | 種類 | 内容 | 価格（案） |
|---|---|---|---|
| `slots_24` | アプリ内アイテム（1 回限り・消費しない） | ずかんの保存枠 +24（12 → 36 体） | 250 円 |
| `frame_pack_1` | 同上 | カードのフレームパック（見た目だけ） | 160 円 |
| `no_ads_pass` | 同上 | こうこくなしパス（広告と同じ 1 日 3 回まで、広告なしで経験値 2 倍） | 320 円 |

有効にする手順: release.yml に `--dart-define=IAP_ENABLED=true`、`check_release.sh` に `--iap` → この文書の §1・§4（デジタル商品: はい）・§5・§6（購入履歴）と説明文・プライバシーポリシー・利用規約を戻す → 商品を作成 → QA_CHECKLIST §8 の課金の項目。商品 ID はあとから変えられないので、アプリの `Product` と同じ綴りで作ります。
