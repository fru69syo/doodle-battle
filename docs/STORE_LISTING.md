# ストア掲載情報と Play Console の申告（Release/QA チーム）

Google Play Console で入力する内容の**推奨回答**をまとめたものです。根拠は `docs/SPEC.md`（§5・§7・§10）と `docs/BACKEND.md` です。
仕様が変わったとき（広告 SDK や課金を入れたとき、Firebase の SDK を増やしたときなど）は、このファイルと Play Console の両方を更新してください。

- 掲載文とグラフィックの実体: `store/metadata/ja-JP/`（fastlane supply の形式。`fastlane android metadata` でアップロードできます）
- 文字数と画像サイズのチェック: `python3 scripts/check_listing.py`（CI でも実行）
- 「PM 判断」と書いた項目は、決めてから入力してください

## 2. 掲載文（ja-JP）

| ファイル | 上限 | 現在 |
|---|---|---|
| `title.txt` | 30 | 7 |
| `short_description.txt` | 80 | 52 |
| `full_description.txt` | 4000 | 約 1600 |
| `changelogs/default.txt`（リリースノート。`<versionCode>.txt` があればそちらを優先） | 500 | 約 110 |

書き方のルール（Play のメタデータポリシー）:
- 「No.1」「最高」などの順位や比較の表現、ユーザーの声の引用、キーワードの羅列、絵文字の多用、関係の無いアプリ名は使いません。
- 説明文に書いた安全の仕組み（チャットなし、保護者ゲート、ガチャなし、広告と購入の前のお知らせ、オンラインの絵は審査のあとで表示、データ削除）は、**リリースするビルドで実際にそうなっていること**を QA で確かめます（`docs/QA_CHECKLIST.md`）。実装が変わったら説明文も直してください。
- 「Teacher Approved」「ファミリー向けに認定」などのバッジを、自分で名乗ってはいけません。

## 3. グラフィック

| 種類 | 規格 | 状態 |
|---|---|---|
| アプリアイコン | 512×512、32 ビット PNG（アルファあり）、1 MB 以下 | **仮** `store/metadata/ja-JP/images/icon.png` |
| フィーチャーグラフィック | 1024×500、JPEG か 24 ビット PNG（アルファなし）、15 MB 以下 | **仮** `store/metadata/ja-JP/images/featureGraphic.png` |
| スマートフォンのスクリーンショット | 2〜8 枚（必須）。JPEG か 24 ビット PNG、各辺 320〜3840 px、長辺は短辺の 2 倍以下。ゲームのおすすめ枠に載るには**縦 1080×1920 以上を 4 枚以上**推奨 | 未作成。`store/metadata/ja-JP/images/phoneScreenshots/1.png` … に置く |
| 7 インチ・10 インチタブレット | 各 8 枚まで。各辺 1080〜7680 px | 任意。タブレット向けとして表示するなら必要（PM 判断） |
| Chromebook | 任意 | 不要 |
| プロモーション動画 | YouTube の URL。広告なし・年齢制限なし・埋め込み可。子ども向けの内容 | 任意 |
| ランチャーアイコン（アプリ内） | アダプティブアイコン（前景・背景・モノクロ） | **仮** `app/assets/launcher/` → `dart run flutter_launcher_icons` |

- 仮のグラフィックは `store/tools/gen_graphics.py` でプログラム生成しています（クレヨンで描いたような丸いモンスター）。文字は **Zen Maru Gothic Black**（SIL Open Font License 1.1、`store/fonts/OFL-ZenMaruGothic.txt`）。フォントのファイルはリポジトリに入れず、google/fonts の固定コミットからダウンロードし、SHA-256 を確かめて使います。
- **本番のグラフィックに差し替える場合**は、同じファイル名で上書きし、`python3 scripts/check_listing.py` と `cd app && dart run flutter_launcher_icons` を実行してください。アダプティブアイコンの前景は 1024×1024 で、**キャラクターを中央 61%（直径）の円の中に収めてください**（端末によって丸や角丸に切り抜かれます）。
- スクリーンショットの注意:
  - 実際のゲーム画面を使います。子どもの**顔や名前、写真**が写らないようにします。
  - 子どもが描いた本物の絵を使うときは、描いた子の保護者から**書面で許可**をもらいます。社内やサンプルの絵を使うのが安全です。
  - 広告や課金の画面を大きく見せないようにします（保護者ゲートと注意書きの画面を見せるのは良い）。

### Teacher Approved について
- ファミリーポリシーに準拠し、ストアで公開されているアプリは自動的に審査の対象になります（申請はできません）。日本語は対象の言語です。
- 評価の観点: 年齢に合っているか、豊かな体験か、楽しいか、デザイン・操作性、広告と課金のやり方（しつこい広告、子どもを購入に誘導する作りは減点）。
- **注意**: 「子どもがほかのユーザーと交流できるソーシャル機能」があるアプリは対象外とされています。オンライン対戦（ほかの子の絵が表示される）がこれに当たると判断される可能性があります。オンラインは初期設定でオフ・保護者ゲートの先・チャットなしですが、Teacher Approved を狙うかどうか、狙うならオンライン機能をどう扱うかは **PM 判断**です。
- 対応のコツ: 広告を見なくても十分に楽しめるバランスにする、課金の訴求を子どもの画面に出さない、文字を読めなくても遊べる、保護者向けの説明画面を用意する。

## 6. データセーフティ

### 6.1 全体の質問

| 質問 | 推奨回答 | 補足 |
|---|---|---|
| 必須のユーザーデータを収集または共有するか | はい | すべて保護者が許可した機能だけで発生する（下の表で「任意」） |
| 転送中のデータはすべて暗号化されているか | はい | Firebase・Anthropic・AdMob・Google Play との通信はすべて TLS。平文の通信は `check_release.sh` で禁止 |
| ユーザーがデータの削除をリクエストできるか | はい | アプリ内（おうちのひと → すべてのデータを削除 → `deleteMyData`）と、ウェブ（`https://fru69syo.github.io/doodle-battle/delete.html`、メールで依頼） |
| アカウントの作成方法 | 「アプリでアカウントを作成できない」を推奨（**PM 判断**） | Firebase の匿名認証だけで、ユーザーが ID やパスワードを作ることはない。ただしサーバー側にプロフィール（表示名・レーティング）があるので、**データ削除の URL（delete.html）を入力する** |
| 独立したセキュリティ審査 | いいえ | |

### 6.2 データの種類（2026-10-09 の実装どおり）

「任意」= 保護者が「おうちのひと」（または初回セットアップ）で機能を許可したときだけ集める（初期値はすべてオフ）。Anthropic と Google（Firebase）は**サービスプロバイダ**（こちらに代わって処理する）なので、Play の定義では「共有」に当たりません。AdMob は Google の「Play のデータ開示」で「収集して共有する」とされているので、広告由来のものは「共有: はい」にします。

| カテゴリ / 種類 | 収集 | 共有 | 任意か | 目的 | どこで（いつ） |
|---|---|---|---|---|---|
| 個人情報 / ユーザー ID | はい | いいえ | 任意 | アプリの機能、不正防止・セキュリティ | Firebase 匿名認証の uid（クラウド判定かオンラインを許可して最初にサーバーを使ったとき）。表示名（プリセット語の組み合わせ）・レーティングと紐づく |
| 写真と動画 / 写真 | はい | いいえ | 任意 | アプリの機能 | 切り抜いた絵の PNG。クラウド判定（`judgeDrawing`、保存しない、Anthropic が処理）と、オンライン登録（`registerCharacter`、Storage に保存し、対戦相手に表示） |
| アプリのアクティビティ / その他のユーザー作成コンテンツ | はい | いいえ | 任意 | アプリの機能 | キャラ名・わざの名前・ステータス・特徴量（オンライン登録時）、通報の理由（選択式） |
| アプリのアクティビティ / アプリの操作 | はい | **はい** | 任意 | アプリの機能、広告、分析、不正防止・セキュリティ | オンライン対戦の行動・勝敗・レート（Firebase、共有なし）。広告の表示・タップ（AdMob、共有あり。広告を許可したときだけ） |
| アプリの情報とパフォーマンス / クラッシュログ | はい | いいえ | 任意 | 分析 | Firebase Crashlytics。「ふぐあいの じょうほうを おくる」をオンにしたときだけ（初期値オフ、マニフェストで無効化済み） |
| アプリの情報とパフォーマンス / 診断 | はい | **はい** | 任意 | 分析、広告、不正防止 | Crashlytics（端末の状態など。共有なし）と AdMob（SDK の性能情報。共有あり） |
| デバイスまたはその他の ID | はい | **はい** | 任意 | 分析、広告、不正防止・セキュリティ | Firebase のインストール ID（Crashlytics をオンにしたとき）、App Check（サーバー機能を許可したとき）、AdMob のアプリセット ID（広告を許可したとき）。**広告 ID は収集しない** |
| 位置情報 / おおよその位置情報 | はい | **はい** | 任意 | 広告、不正防止 | AdMob が IP アドレスからおおよその地域を推定する（広告を許可したときだけ） |
| 金融情報 / 購入履歴 | いいえ | いいえ | | | 購入の処理は Google Play が行う。アプリは所持している商品の ID を端末にキャッシュするだけで、サーバーに送らない（v1.1 でサーバー検証を入れたら「収集する」に変える: docs/COMPLIANCE.md §3.3） |

- 収集**しない**もの（申告不要。`check_release.sh` で権限を検査）: 名前・メール・電話番号・住所、正確な位置情報、連絡先、音声、カレンダー、SMS、ほかのアプリの一覧、ウェブの閲覧履歴、健康情報、**広告 ID**。
- 匿名サインインは保護者がクラウド判定かオンラインを許可するまで行わない（UI.md §5、実装済み）ので、ユーザー ID は「任意」で申告できます。
- Firebase の各 SDK が集めるデータは、Firebase の「Google Play のデータセーフティ セクションの準備」のページで、**使う SDK ごとに**確認してください（Auth、Firestore、Functions、Storage、App Check、Crashlytics）。Google Analytics for Firebase は**使いません**（SPEC §7。`check_release.sh` が Analytics のコンポーネントを見つけたら失敗します）。
- AdMob の「データの開示」（`https://developers.google.com/admob/android/privacy/play-data-disclosure`）: IP アドレス・ユーザーの操作・診断情報・端末とアカウントの ID を「収集して共有する」（目的: 広告、分析、不正防止）。申請の前にその時点の内容でもう一度確認してください。

### 6.3 削除について（プライバシーポリシーと削除ページに記載済み）
- アプリ内: おうちのひと → すべてのデータを削除。端末のデータ、サーバーのプロフィール、登録したキャラ（画像を含む）、対戦の記録、通報、認証ユーザーをすべて削除します（`deleteMyData`、BACKEND §5）。クラッシュレポートの送信もオフになり、未送信のレポートを削除します。購入は Google Play の記録なので消えず、削除のあとに復元されます。
- ウェブ: `delete.html` の手順（メール）で依頼すると、運営が本人確認（アプリの「サポート ID」）をしてから代わりに削除します（30 日以内）。
- 保存しないもの: クラウド判定の画像（処理が終われば破棄）。Anthropic 側では原則 30 日以内に削除（オーナーが契約を確認: RELEASE.md §1.6）。クラッシュログは Crashlytics で 90 日。

## 7. 権限の説明（社内メモ。レビューで聞かれたとき用）

| 権限 | 理由 |
|---|---|
| CAMERA | 紙の絵を撮る、AR。使う直前に許可を求める |
| INTERNET / ACCESS_NETWORK_STATE | クラウド判定とオンライン対戦（どちらも保護者が許可したとき）、広告、オフラインかどうかの判定 |
| WRITE/READ_EXTERNAL_STORAGE（maxSdkVersion 28） | Android 7〜9 で AR の写真をギャラリーに保存するため。Android 10 以降は不要 |
| com.android.vending.BILLING | アプリ内購入（保護者ゲートの先。Play Billing Library 8） |
| WAKE_LOCK / FOREGROUND_SERVICE | ライブラリ（WorkManager など）由来。アプリ自身は使わない |
| （外したもの）AD_ID、ACCESS_ADSERVICES_AD_ID / ATTRIBUTION / TOPICS | Mobile Ads SDK が足すが、子ども向けアプリなのでマニフェストで削除 |

許可リスト以外の権限が入ると `scripts/check_release.sh` が CI とリリースを止めます。足すときは許可リスト・この表・データセーフティを一緒に更新し、PM の承認を得てください。
